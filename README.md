   # Registro de Ponto

Sistema web para registrar entradas e saídas de funcionários, permitindo controle de horários de trabalho de forma simples e eficiente.

  Funcionalidades
- Registro de ponto de entrada e saída
- Visualização do histórico de registros
- Dashboard resumido de horas trabalhadas

  Tecnologias Utilizadas
- PHP
- MySQL 
- Apache via XAMPP
- HTML/CSS
